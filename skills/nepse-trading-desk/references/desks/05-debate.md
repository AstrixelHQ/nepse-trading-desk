# Station 5: Pros and cons (bull case vs bear rebuttal)

The most common way AI stock research misleads people is by only arguing one side. So the desk holds a short debate.

1. **Bull case (why it could work):** the three strongest reasons, each tied to a number from station 3 or 4.
2. **Bear rebuttal (why it could fail):** start with the bull's *strongest* point and show what the evidence says
   against it, then add the risks the bull ignored: valuation, liquidity, a falling sector, lock-in expiry, right
   shares, heavy broker selling, a stretched RSI, results due soon. If you can't find a real bear point, look harder.
3. **Judge:** say in one line which side has more evidence behind it, and which single fact would flip the verdict.

## How to write it for a beginner

Use the headings "Why it could work" and "Why it could fail", three bullets each, every bullet with its evidence in
plain words: "Profit is up 33% on the same quarter last year" beats "strong YoY EPS growth".

Then a verdict line using one of: **leans positive**, **mixed**, **leans negative**, with confidence **high / medium /
low** (see SKILL.md for what earns "high").
